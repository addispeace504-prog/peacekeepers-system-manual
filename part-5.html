Your account settings are where you can update your personal information, change your PIN, and adjust your preferences. This is different from User Management (Part 4) — that's for admins to manage OTHER people. Here, you manage yourself.

🗺️ 3. Area Configuration (Admin) 3. የአካባቢ ማዋቀሪያ (አስተዳዳሪ) 3. Qindaa'ina Naannoo (Bulchaa) 3. ቅጥዒ ከባቢ (ኣማሓዳሪ)

Area Configuration is where administrators define the geographic hierarchy — city, sub-city, district (woreda), ketena, and block. Every dropdown in the system (for officers, crimes, reports, schedules) pulls from this configuration.

የአካባቢ ማዋቀሪያ አስተዳዳሪዎች የጂዮግራፊያዊ ተዋረድን የሚወስኑበት ቦታ ነው — ከተማ፣ ክፍለ ከተማ፣ አውራጃ (ወረዳ)፣ ቀበሌ እና ብሎክ። በሲስተሙ ውስጥ ያለ እያንዳንዱ ዝርዝር (ለመኮንኖች፣ ለወንጀሎች፣ ለሪፖርቶች፣ ለፕሮግራሞች) ከዚህ ማዋቀሪያ ይመጣል።

Qindaa'inni Naannoo bulchitootni akkaataa juugiraafii itti murteessan bakka isaani ti — magaalaa, kutaa magaalaa, aanaa (woreda), ganda, fi blookii. Tarreen sirna keessa jiru hundi (ofiseroonni, yakkoota, gabaasota, sagantaawwan) qindaa'ina kana irraa dhufa.

ቅጥዒ ከባቢ ኣማሓዳሪታት ስርዓት ጂኦግራፊያዊ ተዋረድ ዝውስኑሉ ቦታ እዩ — ከተማ፣ ክፍለ ከተማ፣ ወረዳ፣ ቀበሌን ብሎክን። ኩሉ ዝርዝር ኣብ ስርዓት (ንመኮነንቲ፣ ገበናት፣ ጸብጻባት፣ መርሃግብራት) ካብዚ ቅጥዒ ይመጽእ።

💾 4. Backup & Restore (Admin) 4. ባክአፕ እና መመለስ (አስተዳዳሪ) 4. Baakapii fi Deebisuu (Bulchaa) 4. ባክኣፕን ምምላስን (ኣማሓዳሪ)

A backup is a complete copy of everything in the system — officers, cases, reports, users, attendance, messages. If anything ever goes wrong (data loss, corruption, accidental deletion), a backup is your only way to recover. Only administrators can create or restore backups.

ባክአፕ በሲስተሙ ውስጥ ያለውን ሁሉ ሙሉ ቅጂ ነው — መኮንኖች፣ ጉዳዮች፣ ሪፖርቶች፣ ተጠቃሚዎች፣ ክትትል፣ መልእክቶች። ማንኛውም ነገር ከተሳሳተ (የውሂብ መጥፋት፣ መበላሸት፣ በአጋጣሚ መሰረዝ) ባክአፕ ለመመለስ ብቸኛው መንገድዎ ነው። ባክአፖችን መፍጠር ወይም መመለስ የሚችሉት አስተዳዳሪዎች ብቻ ናቸው።

Baakapiin garagalcha guutuu waan sirna keessa jiru hunda ti — ofiseroonni, galmeewwan, gabaasota, fayyadamtoota, argama, ergaawwan. Yoo waan tokko dogoggora (daataan bade, balleesse, tasaan haqame), baakapiin karaa deebistuu qofa ti. Bulchaan qofa baakapii uumuu yookaan deebisuu danda'a.

ባክኣፕ ምሉእ ቅዳሕ ኩሉ ኣብ ስርዓት ዘሎ እዩ — መኮነንቲ፣ ጉዳያት፣ ጸብጻባት፣ ተጠቀምቲ፣ ተረኽቦ፣ መልእኽትታት። ዝኾነ ነገር እንተጌጋ (ዳታ ጠፊኡ፣ ተበላሽዩ፣ ብኣጋጣሚ ተደምሲሱ) ባክኣፕ ንምምላስ በቶም መንገዲ ጥራይ እዩ። ኣማሓዳሪታት ጥራይ ባክኣፕ ክፈጥሩ ወይ ክምልሱ ይኽእሉ።

Do not keep all backups on the same server. ምርጥ ተግባር: ቅጂ በውጫዊ ድራይቭ ወይም በደመና ማከማቻ ያስቀምጡ። ሁሉንም ባክአፖች በአንድ ሰርቨር ላይ አያቆዩ። Hojii gaarii: garagalcha drive alaa yookaan kuusaa duumessaa irratti olkaa'i. Restore from a Backup ከባክአፕ መመለስ Baakapii Irraa Deebisuu ካብ ባክኣፕ ምምላስ

🚨
Restoring OVERWRITES all current data መመለስ ሁሉንም አሁን ያለውን ውሂብ ይተካል Deebisuun daataa ammaa hunda bakka buusa ምምላስ ኩሉ ዳታ ህሉው ይትክኦ
  • Any changes made AFTER the backup date will be lost.
  • The system auto-creates a safety backup before restoring (see "pre-restore" in the list).
  • Always notify your team before restoring.
  • Do a restore only during low-usage hours (evening/weekend).
  • Only Super Admin should perform restores.
  • ከባክአፕ ቀን በኋላ የተደረጉ ለውጦች ይጠፋሉ።
  • ሲስተሙ ከመመለሱ በፊት የደህንነት ባክአፕ በራስ-ሰር ይፈጥራል (በዝርዝሩ ውስጥ "pre-restore" ይመልከቱ)።
  • ከመመለስዎ በፊት ሁልጊዜ ቡድንዎን ያሳውቁ።
  • በዝቅተኛ አጠቃቀም ሰዓት (ማታ/ቅዳሜና እሁድ) ብቻ ይመልሱ።
  • መመለስ የሚያደርገው ሱፐር አድሚን ብቻ ነው።
  • Jijjiiramni guyyaa baakapii booda raawwatame ni bada.
  • Sirni deebisuu dura baakapii nageenyaa ofumaan uuma (tarree keessatti "pre-restore" ilaali).
  • Yeroo hundaa gareen keessan deebisuu dura beeksisi.
  • Sa'aatii itti fayyadamni gadi aanaa (halkan/torban dhumaa) qofa deebisi.
  • Deebisuu kan raawwatu Super Admin qofa.
  • ለውጥታት ድሕሪ ዕለት ባክኣፕ ዝተገበሩ ይጠፍኡ።
  • ስርዓት ቅድሚ ምምላስ ባክኣፕ ውሕስነት ብራስኡ ይፈጥር (ኣብ ዝርዝር "pre-restore" ርአ)።
  • ወትሩ ቅድሚ ምምላስ ጋንታኻ ኣረድእ።
  • ኣብ ሰዓት ትሑት ኣጠቓቕማ (ለይቲ/ቀዳም ሰንበት) ጥራይ መልስ።
  • ምምላስ Super Admin ጥራይ ክገብሮ ኣለዎ።
  1. 1
    Click "Settings → Backups" "Settings → Backups" ይጫኑ "Settings → Backups" tuqi "Settings → Backups" ጠውቑ
  2. 2
    Find the backup you want to restore ለመመለስ የሚፈልጉትን ባክአፕ ያግኙ Baakapii deebisuu barbaaddu argi ባክኣፕ ክትምልሶ እትደሊ ርኸብ
  3. 3
    Click "Restore" on that row በዚያ ረድፍ ላይ "Restore" ይጫኑ Tarree sana irratti "Restore" tuqi ኣብቲ መስመር "Restore" ጠውቑ ↺ Restore
  4. 4
    Read the confirmation warning carefully የማረጋገጫ ማስጠንቀቂያውን በጥንቃቄ ያንብቡ Akeekkachiisa mirkaneessaa sirriitti dubbisi መተሓሳሰቢ መረጋገጺ ብጥንቃቐ ኣንብብ
  5. 5
    Click "Yes, restore" to confirm ለማረጋገጥ "Yes, restore" ይጫኑ Mirkaneessuuf "Yes, restore" tuqi ንምርግጋጽ "Yes, restore" ጠውቑ
  6. 6
    Wait for restore completion (may take 5–15 minutes) መመለሱ እስኪጠናቀቅ ይጠብቁ (5-15 ደቂቃ ሊወስድ ይችላል) Deebisuun akka xumuramu eegi (daqiiqaa 5–15 fudhachuu danda'a) ምምላስ ክውዳእ ተጸበ (ደቒቕ 5–15 ክወስድ ይኽእል)
  7. 7
    Log out and log back in ውጡ እና እንደገና ይግቡ Ba'ii irra deebi'ii seeni ውጻእ ደጊምካ እቶ
  8. 8
    Verify that data matches the backup date ውሂቡ ከባክአፕ ቀን ጋር የሚመሳሰል መሆኑን ያረጋግጡ Daataan guyyaa baakapii waliin walsimu mirkaneessi ዳታ ምስ ዕለት ባክኣፕ ምስምማዑ ኣረጋግጽ

Backup best practices የባክአፕ ምርጥ ተግባራት Hojii gaarii baakapii ዝበለጹ ተግባራት ባክኣፕ
  • Schedule: Create a backup every Sunday night automatically (if your server supports cron).
  • Before big changes: Backup before bulk operations, new user batches, or system updates.
  • 3-2-1 rule: Keep 3 copies, on 2 different media, with 1 off-site.
  • Test restores: Once every 3 months, test that you can actually restore a backup.
  • Documentation: Keep a list of backup dates and locations in a notebook or shared doc.
  • መርሃግብር: በየእሁዱ ማታ በራስ-ሰር ባክአፕ ይፍጠሩ (ሰርቨሩ cron ከደገፈ)።
  • ከትልቅ ለውጦች በፊት: ከጅምላ ስራዎች፣ ከአዲስ የተጠቃሚ ቡድኖች ወይም ከሲስተም ማሻሻያዎች በፊት ባክአፕ ያድርጉ።
  • የ3-2-1 ደንብ: 3 ቅጂዎች፣ በ2 የተለያዩ ሚዲያዎች፣ 1 ከቦታ ውጪ።
  • መመለስን ይፈትሹ: በየ3 ወሩ አንዴ ባክአፕ በትክክል መመለስ እንደሚችሉ ይፈትሹ።
  • ሰነድ: የባክአፕ ቀኖችን እና ቦታዎችን በማስታወሻ ደብተር ወይም በጋራ ሰነድ ያስቀምጡ።

  • Deebisuu qori: Ji'a 3 ji'a 3 al tokko baakapii dhugaan deebisuu dandeessan qori.
  • Galmee: Guyyaawwan fi bakkeewwan baakapii galmee yookaan sanada waliin galmeessi.
  • መርሃግብሪ: ሰንበት ለይቲ ባክኣፕ ብራስኡ ፍጠር (ሰርቨርካ cron እንተድግፍ)።
